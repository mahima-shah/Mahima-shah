### Selected Work

**[Scalable Search Engine](https://github.com/mahima-shah/scalable-search-engine)**  
Distributed search engine over 28K+ documents using MapReduce, TF-IDF, PageRank, Flask, and REST APIs.

**[Instagram Clone](https://github.com/mahima-shah/instagram-clone)**  
Full-stack social media application built with React, Flask, SQLite, and REST APIs, with authentication, feeds, likes, comments, follows, and infinite scroll.

**[RAG Reliability Checker](https://github.com/mahima-shah/semantic-entropy-rag)**  
Experimental RAG prototype that uses disagreement across multiple LLM responses to flag potentially unreliable answers and trigger more constrained retries.

**[LexNews](https://github.com/mahima-shah/LexNews)**  
Mobile-first legal news prototype built with React and Vite, combining article discovery, search, saved content, and an integrated AI assistant concept.
